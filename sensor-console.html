มือถือทุกเครื่องมีเข็มทิศ ไจโรสโคป ความเร่ง GPS กล้อง ไมค์ และมอเตอร์สั่นอยู่แล้ว หน้านี้เรียกใช้ผ่าน Web API ล้วน ๆ ไม่มี native code — กดปุ่มแต่ละโมดูลด้านล่างเพื่อขอสิทธิ์และดูค่าจริงแบบสด
กำลังตรวจสอบแพลตฟอร์ม…
⚠ หน้านี้ไม่ได้เปิดผ่าน HTTPS — iOS Safari จะปฏิเสธ Geolocation, Camera/Mic และ Motion API ทั้งหมด ต้อง deploy ผ่าน HTTPS จริง (หรือ localhost ตอนพัฒนา) เท่านั้น
01เข็มทิศ
รอเริ่ม
อ่านทิศทางที่มือถือหันอยู่ผ่าน DeviceOrientationEvent. iOS ให้ค่า webkitCompassHeading ตรง ๆ (0° = เหนือ) ส่วน Android ต้องคำนวณจาก alpha เอง

02เซ็นเซอร์ความเร่ง
รอเริ่ม
อ่านความเร่งตามแกน X/Y/Z ผ่าน DeviceMotionEvent.accelerationIncludingGravity ใช้ตรวจจับการเขย่า การเอียง หรือการเคลื่อนไหว
ยังไม่มีข้อมูล
ข้อจำกัด: ใช้ permission request เดียวกับไจโรสโคปบน iOS (DeviceMotionEvent.requestPermission()) กดครั้งเดียวได้ทั้งคู่ถ้าเขียนรวมกัน
03ไจโรสโคป
รอเริ่ม
อ่านอัตราการหมุน (deg/s) รอบแต่ละแกนผ่าน DeviceMotionEvent.rotationRate — alpha/beta/gamma
ยังไม่มีข้อมูล
ข้อจำกัด: iOS Safari บางเวอร์ชันคืนค่า null สำหรับ rotationRate แม้ได้สิทธิ์แล้ว — เป็น known limitation ไม่ใช่บั๊กของโค้ด
04GPS / ตำแหน่ง
รอเริ่ม
ใช้ navigator.geolocation.watchPosition() ได้ทั้งพิกัด ความแม่นยำ ความเร็ว และทิศ (heading) แบบสดต่อเนื่อง
ยังไม่มีข้อมูล
ข้อจำกัด: iOS จะถามสิทธิ์ครั้งเดียวต่อ session ของ Safari ถ้าปฏิเสธไปแล้วต้องไปเปิดใหม่ใน Settings → Safari → Location ด้วยตัวเอง โค้ดสั่งเปิดใหม่ไม่ได้
05กล้อง
รอเริ่ม
ใช้ navigator.mediaDevices.getUserMedia({video:true}) เปิด live preview ได้ทันที ถ่ายภาพนิ่งด้วย <canvas> วาดเฟรมจาก video
ข้อจำกัด: เว็บทำได้แค่ preview/ถ่ายภาพ/อัดวิดีโอสั้น ๆ ผ่าน MediaRecorder — เข้าถึงโหมด RAW, Portrait, หรือควบคุม hardware ระดับลึกแบบแอปเนทีฟไม่ได้เลย
06ไมโครโฟน
รอเริ่ม
ใช้ getUserMedia({audio:true}) ร่วมกับ Web Audio API (AnalyserNode) วัดระดับเสียงสดแบบ real-time
ยังไม่มีข้อมูล
ข้อจำกัด: ไม่มีสิทธิ์ background — พอสลับแท็บหรือ lock หน้าจอ mic จะถูกตัดทันที ต่างจากแอปเนทีฟที่อัดต่อได้
07มอเตอร์สั่น
รอเริ่ม
มาตรฐานคือ navigator.vibrate(pattern) — ไม่ต้องขอสิทธิ์ เรียกแล้วสั่นทันที
ยังไม่มีข้อมูล
ข้อจำกัด (สำคัญ): iOS Safari ไม่รองรับ Vibration API เลย — ปุ่มจะกดได้แต่ไม่มีอะไรเกิดขึ้นจริง ต้องใช้แอปเนทีฟหรือ Haptic API ของ PWA บางตัวแทน (ยังไม่เสถียร) นี่คือความต่างของแพลตฟอร์มที่ชัดที่สุดในหน้านี้

สรุป: ข้อจำกัดที่ต้องรู้ก่อนใช้จริง
